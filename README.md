### Setting Soundy up and running

###### 1. Installing requirements
Soundy requires you to install [VB Virtual Audio Device](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack45.zip) manually in order to function properly

###### 2. Installing Soundy
Soundy is a *portable* software, so you just go to [the downloads page](https://github.com/ZesGit/Soundy/releases), unzip the file, and open the executable. Just as easy as it looks!
